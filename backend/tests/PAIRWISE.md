# Pairwise-тестирование фильтров поиска (AllPairs)

## Что это за техника

**Pairwise (AllPairs)** — комбинаторная техника, при которой покрываются **все пары** значений параметров, а не полный декартовый продукт. Это сильно сокращает число тестов при сохранении выявления ошибок, связанных с взаимодействием двух факторов.

Идея: полное комбинирование 5 фильтров по 3 значения даёт 3⁵ = 243 теста. Pairwise покрывает все пары за ~20–40 тестов.

---

## Параметры фильтров для pairwise

Эндпоинт `GET /animals/` принимает:

| Параметр   | Классы эквивалентности        | Представители значений         |
|-----------|-------------------------------|--------------------------------|
| search    | пустой / непустой             | `""`, `"Мурзик"`               |
| species_id| не задан / задан              | `None`, `1`                    |
| gender_id | не задан / задан              | `None`, `1`                    |
| min_age   | не задан / 0 / >0             | `None`, `0`, `5`               |
| max_age   | не задан / задан              | `None`, `10`                   |
| color_id  | не выбраны / 1 цвет / 2+ цвета| `[]`, `[1]`, `[1, 2]`          |

---

## Использование allpairspy

```python
from allpairspy import AllPairs

parameters = [
    ["", "Мурзик"],           # search
    [None, 1],                # species_id
    [None, 1],                # gender_id
    [None, 0, 5],             # min_age
    [None, 10],               # max_age
    [[], [1], [1, 2]],        # color_id
]

for i, combo in enumerate(AllPairs(parameters)):
    # combo = (search, species_id, gender_id, min_age, max_age, color_id)
    # используем combo для GET-запроса
```

## Тесты

В `test_search_filters.py` каждый pairwise-комбинация превращается в отдельный тест:

- `client.get('/animals/', query_string=params)` -> статус 200
- страница рендерится без исключений

Таким образом проверяется устойчивость фильтров при различных сочетаниях параметров.

---

## Результат

Для 6 параметров с 2–3 значениями:
- **Полный перебор**: 2×2×2×3×2×3 = 72 теста
- **Pairwise (AllPairs)**: 10 тестов

Покрытие пар сохраняется, число тестов уменьшается примерно в 7 раз.
