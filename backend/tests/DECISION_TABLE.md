# Таблица принятия решений: validate_queue_eligibility()

Функция проверяет, может ли пользователь встать в очередь на усыновление животного.

## Условия

| ID | Условие | Описание |
|----|---------|----------|
| C1 | is_available | Животное доступно для усыновления |
| C2 | profile | Анкета заполнена (profile не None) |
| C3 | existing_entry | Пользователь уже в очереди на это животное |
| C4 | active_count < max_active | У пользователя менее 3 активных заявок |
| C5 | house_ok | Если требуется дом — у пользователя housing_type='house' |
| C6 | rooms_ok | rooms_count >= animal.min_rooms |
| C7 | children_ok | Если животное не для детей — у пользователя нет детей |
| C8 | pets_ok | Если животное не с другими — у пользователя нет питомцев |

## Таблица решений

| # | C1 | C2 | C3 | C4 | C5 | C6 | C7 | C8 | Результат | Описание |
|---|----|----|----|----|----|----|----|-----|-----------|----------|
| 1 | Y | Y | N | Y | Y | Y | Y | Y | **SUCCESS** | Все условия выполнены |
| 2 | N | - | - | - | - | - | - | - | FAIL | Животное недоступно |
| 3 | Y | N | - | - | - | - | - | - | FAIL | Нет анкеты |
| 4 | Y | Y | Y | - | - | - | - | - | FAIL | Уже в очереди |
| 5 | Y | Y | N | N | - | - | - | - | FAIL | Лимит заявок (≥3) |
| 6 | Y | Y | N | Y | N | - | - | - | FAIL | Нужен частный дом |
| 7 | Y | Y | N | Y | Y | N | - | - | FAIL | Недостаточно комнат |
| 8 | Y | Y | N | Y | Y | Y | N | - | FAIL | Не подходит для детей |
| 9 | Y | Y | N | Y | Y | Y | Y | N | FAIL | Не уживается с другими |

**Обозначения:** Y = да, N = нет, - = не проверяется (ранний выход)

## Порядок проверок

Условия проверяются последовательно. При первом нарушении функция возвращает FAIL и не проверяет остальные.

1. is_available -> если N, выход
2. profile -> если N, выход
3. existing_entry -> если Y, выход
4. active_count >= max_active -> если Y, выход
5. C5, C6, C7, C8 -> все накапливаются в список errors; если есть хоть одна ошибка — FAIL
