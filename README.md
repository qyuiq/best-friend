# Лучший друг — учебное веб-приложение для тестирования

**Лучший друг** — это учебный веб-сервис виртуального приюта для животных, предназначенный для демонстрации и отработки методов тестирования программного обеспечения (модульное, интеграционное, функциональное тестирование, тестирование API, pairwise и др.). Приложение реализовано на Flask с использованием SQLite и Bootstrap.

## 🚀 Возможности

- **Ролевая модель**: гость, зарегистрированный пользователь, администратор.
- **Регистрация и аутентификация** с секретным словом.
- **Личный кабинет**: заполнение и редактирование анкеты (ФИО, контакты, условия проживания, наличие детей/животных, опыт). Маска ввода телефона.
- **Каталог животных**: фильтрация по виду, полу, возрасту, цвету (логическое ИЛИ), поиск по имени, пагинация.
- **Карточка животного**: фотогалерея, описание, особые потребности, кнопка подачи заявки.
- **Очередь на усыновление**:
  - Автоматическая проверка бизнес-правил (требования к жилью, количеству комнат, совместимость с детьми и другими животными).
  - Ограничение: не более 3 активных заявок.
  - Отмена заявки.
- **Административная панель**:
  - Управление животными (добавление, редактирование, скрытие/показ, полное удаление).
  - Загрузка нескольких фотографий (с возможностью установки главной).
  - Управление очередями (одобрение/отклонение заявок).
  - Просмотр пользователей и их анкет.
- **Логирование изменений** карточек животных.
- **Документация API** (Swagger) — доступна после запуска по адресу `/apidocs`.

## 🛠 Технологии

- **Backend**: Python 3.11+, Flask, SQLAlchemy, Flask-Login, Flask-WTF, Werkzeug
- **База данных**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5, Inputmask
- **Тестирование**: pytest, allpairspy, unittest.mock
- **Документация API**: flasgger (Swagger UI)
- **Контроль версий**: Git, GitHub

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/qyuiq/best-friend.git
cd best-friend
```

### 2. Создание и активация виртуального окружения

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных

База данных `instance/shelter.db` уже включена в репозиторий с тестовыми данными (пользователи, животные, справочники).


### 5. Запуск приложения

```bash
cd backend
python run.py
```

После запуска сервер будет доступен по адресу:  
[http://127.0.0.1:5000](http://127.0.0.1:5000)

### 6. Тестовые учётные записи

| Роль          | Логин   | Пароль    |
|---------------|---------|-----------|
| Администратор | admin   | admin123  |
| Пользователь  | user    | user123   |
| Пользователь  | test_user    | test_user123   |

Секретное слово для регистрации: `Приют2026`.

## 🧪 Запуск тестов

Все тесты находятся в папке `tests/`. Для их выполнения:

```bash
pytest backend/tests/ -v
```

Отдельные наборы:

- Модульные тесты бизнес-логики: `pytest tests/test_business_logic.py -v`
- Мок-тесты очереди: `pytest tests/test_queue_service.py -v`
- Pairwise-тесты фильтров: `pytest tests/test_search_filters.py -v`
